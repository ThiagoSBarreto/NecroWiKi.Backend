# NecroWiKi.Backend

NecroWiKi.Backend is the API and service layer that powers the NecroWiKi platform. It provides endpoints for user registration flows and for the arcade/game system features exposed to the Angular frontend.

## Project purpose

This backend is responsible for:

- handling account registration for supported communities such as WoW and Ragnarok;
- exposing game-system metadata and ROM/image resources;
- uploading ROM and cover files to the game storage directory;
- providing a centralized API layer for the NecroWiKi frontend and related services.

## Architecture

The solution is organized in a layered ASP.NET Core structure:

```text
src/
  NecroWiKi.API/
    Controllers/         - HTTP endpoints for register and game-system APIs
    Program.cs           - API composition and dependency registration

  NecroWiKi.Application/
    Interfaces/          - application contracts
    Services/            - business services for registration and game systems
    Models/              - API and DTO models

  NecroWiKi.Infrastructure/
    - infrastructure and data-related support code
```

## Main endpoints

The main controllers expose the following routes:

- `POST /api/Register/wow`
- `POST /api/Register/ragnarok`
- `GET /api/GameSystem/{system}/roms`
- `GET /api/GameSystem/{system}/image/{fileName}`
- `GET /api/GameSystem/{system}/rom/{fileName}`
- `POST /api/GameSystem/{system}/upload`

## Technology stack

- .NET 10
- ASP.NET Core Web API
- OpenAPI / API explorer support
- Dependency injection
- CORS policies
- MySQL connection settings through configuration files

## Run locally

From the backend repository root:

```bash
dotnet restore
DOTNET_ENVIRONMENT=Development dotnet run --project src/NecroWiKi.API/NecroWiKi.API.csproj
```

The API will be available from the configured ASP.NET Core host, typically through the local development endpoint generated by the runtime.

## Configuration

The application reads endpoint and database configuration from the `appsettings.json` and `appsettings.Development.json` files, including:

- logger settings;
- connection strings for WoW and Ragnarok services;
- game settings and shared storage paths.
